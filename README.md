# About Me:
Hi, I’m Dipshan. I enjoy building backend systems, cloud infrastructure, developer tools, and solving problems that require a lot of debugging and thinking.

Most of my work is around Python, Django, FastAPI, AWS, Kubernetes, Docker, and Terraform. I’ve worked on APIs, authentication, background jobs, queues, rate limiting, isolated coding environments, automated deployments, infrastructure automation, and AI-powered developer tools.

I also work with React and Next.js when needed, and I’m continuously improving my system design, DSA, cloud, and infrastructure skills.
